# TrackGuard-AI

TrackGuard AI is a computer vision-based traffic monitoring and vehicle tracking project. It uses vehicle detection, object tracking, and virtual boundary analysis to identify potential traffic events from video footage.

The project is currently under development, with its core pipeline implemented and further testing, optimization, and improvements planned.

## Features

- Vehicle detection using YOLO
- Multi-object tracking using ByteTrack
- Virtual boundary crossing detection
- Video upload and frame extraction
- Evidence capture for detected events
- Audio verification
- Interactive dashboard for video analysis

## Tech Stack

- Python
- YOLO
- ByteTrack
- OpenCV
- PyTorch
- Streamlit
- Pydantic
- Pytest

## Project Status

The core detection, tracking, boundary analysis, evidence capture, and dashboard workflows have been implemented.

Backend testing has been completed for the current development stage. Further real-world video validation, performance optimization, and bug fixes are still pending.

## Roadmap

- Edge-case handling

TrackGuard AI is an ongoing engineering project focused on exploring practical applications of computer vision in traffic monitoring and intelligent video analysis.
